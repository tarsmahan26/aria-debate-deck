# Aria's Debate Deck

Flashcards and quizzes for learning logical fallacies and key Scripture for apologetics and debate.

- 22 logical fallacies, each with a definition, how to spot it, how to answer it, and examples from abortion, slavery and faith debates (taken from every side).
- 44 Bible verses (ESV) grouped by topic: how to debate, faith and reason, abortion, slavery, and other faiths.
- Spaced repetition: cards you know come back less often, cards you miss come back sooner.

## How to use it

**Easiest:** open https://tarsmahan26.github.io/aria-debate-deck/, then on a phone or tablet choose "Add to Home Screen".

**Offline:** download `index.html` (or the whole repository as a ZIP) and open the file in any web browser. No install needed. Fonts load from the internet when available and fall back to built-in fonts when offline.

Progress is saved in the browser on the device you use. Using a different browser or device starts fresh.

## Editing

All cards live in `index.html`, in the `FALLACIES` and `VERSES` lists near the top of the script. Add a card by copying an existing entry and changing the text.
